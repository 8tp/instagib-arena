# Code of Conduct

Instagib Arena follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1. The goal is a focused, welcoming project space where people can
report bugs, share ideas, review code, and playtest without needless friction.

## Our Standards

Examples of behavior that helps the project:

- Treat other contributors and players with respect, even during disagreement.
- Keep criticism specific to code, gameplay, documentation, design, or process.
- Assume good intent, and ask clarifying questions before escalating a conflict.
- Respect maintainers' decisions about scope, review timing, licensing, and
  project direction.
- For game-integrity issues, report privately instead of publishing working
  exploits or cheat instructions.

Examples of behavior that is not acceptable:

- Insults, intimidation, personal attacks, or sustained disruption.
- Harassment, threats, stalking, or unwanted sexual attention.
- Publishing private information without explicit permission.
- Discriminatory language or conduct based on identity, background, ability, or
  other personal characteristics.
- Using project spaces to promote spam, scams, malware, cheats, or unrelated
  commercial activity.

## Scope

This Code of Conduct applies in all project spaces, including GitHub issues, pull
requests, discussions, chat/community spaces if any are added, playtests, and
public project-related interactions.

It also applies when someone is representing the project, such as by speaking on
behalf of the project, using official project accounts, or operating an official
community space.

## Enforcement

Report Code of Conduct concerns to the maintainer, currently
[@8tp](https://github.com/8tp). If the concern is security-sensitive or involves a
working exploit, use GitHub private vulnerability reporting as described in
[SECURITY.md](SECURITY.md).

Maintainers may take any action they judge appropriate, including removing
content, requesting edits, warning a participant, limiting participation, or
banning a participant from project spaces. Enforcement decisions should be
proportionate to the issue and should prioritize the health of the project and
its contributors.
