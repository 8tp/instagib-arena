# Reference images (the quality bar)

Drop real screenshots here. Critic agents compare our output against these, blind.

- `3d/` — arena FPS in-match frames: Diabotical, Quake Champions, Splitgate 2. Include one
  wide arena shot with lighting/shadows, one mid-fight frame with a rail/beam effect, one
  first-person weapon-idle frame.
- `ui/` — front-end: Diabotical main menu + settings, Splitgate 2 lobby, one modern
  scoreboard, one killfeed/hit-marker frame.
- `design/shots/` (sibling) — our own captures, named `<track>-<round>-<scene>.png`.

Keep images under 2 MB. Nothing here ships; the folder is for critique only.
